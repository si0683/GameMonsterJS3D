GameMonsterJS3D
GitHub

Стек для 3D-игры одной командой

Vite + Three.js + React Three Fiber + Drei + Rapier — команда создаёт папку с игрой и сама ставит все пакеты. Внутри готовый уровень с физикой.

Как начать

  1. Установите Node.js 20.19+ · проверить: node -v
  2. Создайте проект
    npm create gamemonsterjs3d@latest my-game
  3. Запустите
    cd my-game && npm run dev

Откроется на http://localhost:5173, готовая сборка — npm run build → dist/. Пока пакета нет в npm, вместо шага 2: npx github:si0683/GameMonsterJS3D my-game
