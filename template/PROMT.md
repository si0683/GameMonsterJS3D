## 7. Технические требования

- **Площадка публикации (SDK):** [ ] без SDK (сайт, GitHub Pages, itch.io) [ ] Яндекс Игры (`--sdk=yandex`: реклама, облачные сохранения, лидерборд — см. `YANDEX.md`). Все вызовы платформы — только через `platform` из `src/platform`.
- Стек не меняй: React Three Fiber + Drei + React Three Rapier + Howler + zustand + Vite + TypeScript. Новые пакеты — только с объяснением, зачем они нужны (например, `@react-three/postprocessing`, `leva` для отладки).
- Сцена — JSX R3F. Логика кадра — в `useFrame` с `delta`. Никаких `setState` в каждом кадре: меняй refs, состояние читай через `useGame.getState()`.
- Производительность:
  - 60 FPS на компьютере и 30+ на среднем телефоне;
  - повторяющиеся объекты — через `<Instances>` или `<Clone>`;
  - сжатые модели (`gltf-transform` / Draco);
  - тени только там, где нужны;
  - `dpr={[1, 2]}`.
- Физика — только Rapier: `<RigidBody>`, коллайдеры, сенсоры для триггеров. Силы и импульсы умножай на `delta`.
- Все числа баланса — в `src/config.ts`, тексты для игрока — на «русском».
- Музыка включается после первого клика (правило браузеров).
- Пути к файлам — через `import.meta.env.BASE_URL`, чтобы игра работала на GitHub Pages.

## 8. Как работать

1. Прочитай `AGENTS.md`, `README.md` и код в `src/`.
2. Задай мне до 8 вопросов — только о том, без чего нельзя начать. По остальному прими решения и перечисли их.
3. Покажи план: компоненты сцены, состояние в zustand, модели и звуки, этапы. Жди моего «ок».
4. Сначала сделай **играбельный прототип** на примитивах, потом графику. Этапы:
   - этап 1 — прототип: камера, управление, физика, одна механика, победа и поражение;
   - этап 2 — враги, предметы, уровни;
   - этап 3 — меню, HUD, экраны, сохранение;
   - этап 4 — модели, анимации, свет, звук, эффекты;
   - этап 5 — производительность, телефон, полировка.
5. Демо-уровень шаблона замени на мою игру. Ненужные файлы удали.
6. После каждого этапа запускай `npm run build` и исправляй ошибки. Затем коротко напиши, что готово и как проверить. Для проверки в режиме разработки есть `window.useGame` и `window.player`; коллайдеры видно через `<Physics debug>`.
7. В конце обнови `README.md`: управление, где менять баланс и уровни, как добавить модель, как выложить.
