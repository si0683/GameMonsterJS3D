# PROMT.md — техническое задание для ИИ: 3D-игра

Шаблон для игры на стеке **GameMonsterJS3D**: Vite · Three.js · React Three Fiber · Drei · Rapier · Howler.js · zustand · TypeScript.

## Как пользоваться

1. Создайте проект:
   ```bash
   npm create gamemonsterjs3d@latest my-game
   ```
   Этот файл уже лежит в папке проекта. Отдельно его можно скачать по ссылке: https://raw.githubusercontent.com/si0683/GameMonsterJS3D/main/PROMT.md
2. Заполните раздел **«Промт»** ниже:
   - замените всё в `«кавычках-ёлочках»`;
   - отметьте нужное `[x]`;
   - удалите строки, которые не подходят.

   Не знаете, что ответить, — напишите «на усмотрение ИИ».

3. Откройте папку проекта в ИИ-ассистенте (Claude Code, Cursor, Codex, Windsurf и т. п.) и напишите:

   > Прочитай PROMT.md и AGENTS.md и сделай игру по разделу «Промт». Начни с плана и вопросов.

   Если ассистент работает только в чате, вставьте в него текст от `НАЧАЛО ПРОМТА` до `КОНЕЦ ПРОМТА`.

4. Ответьте на вопросы, утвердите план и играйте после каждого этапа: `npm run dev` → http://localhost:5173.

Самое важное — раздел 1 (идея и игровой цикл), раздел 2 (камера) и раздел 6 (модели). 3D-игры тяжелее 2D: начинайте с небольшого объёма.

### 7. Технические требования

- Стек не меняй: React Three Fiber + Drei + React Three Rapier + Howler + zustand + Vite + TypeScript. Новые пакеты — только с объяснением, зачем они нужны (например, `@react-three/postprocessing`, `leva` для отладки).
- Сцена — JSX R3F. Логика кадра — в `useFrame` с `delta`. Никаких `setState` в каждом кадре: меняй refs, состояние читай через `useGame.getState()`.
- Производительность:
  - 60 FPS на компьютере и 30+ на среднем телефоне;
  - повторяющиеся объекты — через `<Instances>` или `<Clone>`;
  - сжатые модели (`gltf-transform` / Draco);
  - тени только там, где нужны;
  - `dpr={[1, 2]}`.
- Физика — только Rapier: `<RigidBody>`, коллайдеры, сенсоры для триггеров. Силы и импульсы умножай на `delta`.
- Все числа баланса — в `src/config.ts`, тексты для игрока — на «русском».
- Музыка включается после первого клика (правило браузеров).
- Пути к файлам — через `import.meta.env.BASE_URL`, чтобы игра работала на GitHub Pages.

## Пример заполнения (коротко)

> **1.** Мини-гольф «Остров»: 9 лунок на летающих островах, цель — меньше ударов. Похоже на Golf With Your Friends. Для всех, сессия 10 минут.
> **2.** Камера — орбита вокруг мяча. Удар: зажать ЛКМ и потянуть (сила как у рогатки). На телефоне — то же пальцем.
> **3.** Мяч — Rapier `ball`, трение 0.6; препятствия — мельницы, трамплины, песок (замедляет); упал с острова — +1 удар и возврат.
> **4.** 9 лунок из примитивов, яркое небо, мягкие тени.
> **6.** Low-poly, модели Kenney Minigolf Kit (CC0), звуки удара и лунки.

## Подсказки

- **3D-проект делайте маленькими шагами.** Сначала «кубик, который двигается и прыгает», потом всё остальное.
- **Модели проверяйте до того, как отдать ИИ.** Откройте .glb на https://gltf-viewer.donmccurdy.com: виден размер, анимации и названия частей.
- **Тормозит на телефоне** — попросите ИИ: «уменьши качество на телефонах: без теней, dpr 1, меньше объектов».
- **Нашли баг** — опишите шаги и приложите скриншот; для физики помогает `<Physics debug>`.
