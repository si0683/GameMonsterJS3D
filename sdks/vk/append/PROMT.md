
## 10. Платформа: VK Игры

Проект создан с SDK VK Игр (`--sdk=vk`). Прочитай `VK.md`. Требования каталога: https://dev.vk.com/ru/games/getting-started

- **Реклама между раундами:** [ ] да (уже есть) [ ] нет. Где ещё: «например: после каждого 2-го уровня»
- **Реклама за награду:** «например: +1 жизнь после проигрыша / удвоить монеты»
- **Сохранения во ВКонтакте:** «что сохранять: рекорд, уровни, настройки» (до 4096 байт)
- **Покупки:** [ ] не нужны [ ] нужны — тогда нужен свой сервер для платёжных уведомлений VK
- **Рейтинг друзей:** [ ] не нужен [ ] нужен (окно VK `VKWebAppShowLeaderBoardBox`)

Все вызовы VK — только через `platform` из `src/platform`. Новые возможности сначала добавь в интерфейс `Platform`.
