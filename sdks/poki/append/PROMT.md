
## 10. Платформа: Poki

Проект создан с SDK Poki (`--sdk=poki`). Прочитай `POKI.md`. Документация: https://developers.poki.com/guide/sdk-html5

- **Реклама между раундами:** [ ] да (уже есть) [ ] нет. Где ещё: «…»
- **Реклама за награду:** «например: продолжить после проигрыша / удвоить награду»
- **Языки:** [ ] английский (обязательно) [ ] другие: «…»

Все вызовы SDK — только через `platform` из `src/platform`. Новые возможности сначала добавь в интерфейс `Platform`.
