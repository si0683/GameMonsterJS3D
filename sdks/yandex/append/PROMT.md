
## 10. Платформа: Яндекс Игры

Проект создан с SDK Яндекс Игр (`--sdk=yandex`). Прочитай `YANDEX.md`. Игра должна пройти модерацию Яндекс Игр: https://yandex.ru/dev/games/doc/ru/concepts/requirements

- **Реклама между раундами:** [ ] да (уже есть) [ ] нет. Где ещё: «например: после каждого 2-го уровня»
- **Реклама за награду:** «например: продолжить после падения / ускорение на старте / новый скин»
- **Лидерборд:** «по времени прохождения (как в шаблоне) / по очкам / не нужен». Техническое имя: «score»
- **Облачные сохранения:** «что сохранять: рекорд, открытые уровни, валюту, настройки»
- **Языки:** [ ] русский [ ] английский [ ] турецкий [ ] другие: «…» — язык выбирается автоматически через SDK
- **Покупки внутри игры:** [ ] не нужны [ ] нужны: «что продаём»

Все вызовы SDK — только через `platform` из `src/platform`. Новые возможности SDK сначала добавь в интерфейс `Platform`.
